# Clash Royale App

Aplicación web inspirada en el universo de Clash Royale que permite explorar cartas, visualizar información detallada y experimentar una interfaz dinámica basada en el juego.

---

## Características

- Visualización de cartas
- Buscador de jugadores
- Información detallada de cada carta
- Interfaz moderna y simple
- Renderizado dinámico con JavaScript
- Diseño adaptable

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
